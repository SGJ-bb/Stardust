程序化像素渲染演示

全部由 Canvas 代码逐像素绘制 · 无图片 API · 无网络请求 · 可离线打开

人物 · 待机像素精灵 物品 · 像素图鉴 技法 · 高光/暗部 + 1px描边 + 接地阴影
说明：这一页完全没有引用任何图片文件，也没有调用图片生成 API。画面上每个人物、每个物品，都是 JavaScript 里硬编码的像素位图，通过 Canvas fillRect 逐格上色生成。
这正是游戏当前采用的程序化渲染路径（characters.ts / tileset.ts 同一思路）：引擎本地即可产出，且给后续"参考图 → 预烘焙 sprite 资产"的高速替换留了接口——观感可从演示版提升到参考图级别的静态资源，但依然零运行时 API、零成本。
