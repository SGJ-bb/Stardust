# 怎么把 ADB 连上（Redmi Note 14 5G / HyperOS 实测路径）

> 一句话结论：**「无线调试」那个端口不能给这个应用用**，要么走 `adb tcpip 5555`（需 USB 一次），
> 要么等我实现「配对码 + TLS」那条（P1）。下面三档说清楚。

## 1. 三种端口，别混

| 端口 | 从哪来 | 走的协议 | 本应用现在能用吗 |
|---|---|---|---|
| `tcpip 5555` | 电脑执行一次 `adb tcpip 5555` | 明文 adb | ✅ **能** |
| 无线调试「IP:端口」（你截图里的 41127） | 开发者选项 → 无线调试 | **TLS + 首次配对** | ❌ 不能（缺 SPAKE2 配对 + TLS 客户端证书） |
| 配对端口（你截图里的 44311） | 「使用配对码配对设备」 | TLS-PSK | ❌ 不能（同上） |

所以：**扫到 41127 也没用**，那不是配置问题，是协议不通用。之前界面写"扫描无线调试端口"会误导，
已改成「扫描本机端口」，并且会过滤掉局域网里别人的设备（你这次扫到的 `172.26.35.185` 就是别人手机）。

## 2. 你现在就能连上的做法（约 3 分钟，只需一次）

1. **手机**：设置 → 关于手机 → 连点「OS 版本」7 次 → 开发者选项打开；
   打开 **USB 调试**；小米还建议打开 **USB 调试（安全设置）**（否则 `input` 注入会被拦）。
2. **用 USB 线连电脑**，手机弹「允许 USB 调试吗」→ 勾选「一律允许」→ 允许。
3. **电脑**：双击 `F:\stradust\android\tools\adb_elevate.bat`。
   它会一次性做完：运行时权限、`WRITE_SECURE_SETTINGS`、AppOps、无障碍、通知使用权、电池白名单，
   最后执行 `adb tcpip 5555` 打开明文端口。
4. **拔线**。打开应用 → 设置 → 无障碍 → 「自建 ADB 通道」→ 端口填 **5555** → **连接并测试**。
5. 期望状态：`已连接 · uid=2000(shell)`。
   如果显示 `uid=0(root)`，说明你的机器被 root 过；未 root 的正常机一定是 `shell`。
6. 想核对能力：`adb logcat -s AdbSelfTest`（拔线前先在电脑上挂 `adb logcat`），会看到五项
   `cap settings put/get/delete`、`cap screencap: ok`、`cap input tap`。

## 3. 常见报错对照

| 界面提示 | 原因 | 怎么办 |
|---|---|---|
| 连不上 `127.0.0.1:5555` | 端口没开（重启过手机会失效） | 重跑 `adb tcpip 5555`，或重跑一遍脚本 |
| 超时：端口没开或没在设备上点「允许」 | 密钥没被信任 | 手机解锁，重新点「连接并测试」，**60 秒内在手机上点允许** |
| `uid=` 为空 / 命令全 exit=-1 | adbd 已断（USB 拔出但 tcpip 没生效） | 插线重跑脚本的第 7 步 |
| 脚本第 1~6 步 ok，第 7 步失败 | 部分系统禁用 tcpip | 开发者选项里把「无线调试」关掉再试 |

## 4. 重启手机之后

`adb tcpip` 不持久，重启后端口关掉 —— 现阶段只能再插一次线跑脚本。
这就是为什么要做 P1；P1 完成后改成「输入一次配对码」，重启后也可以自动重连（靠 mDNS 找端口）。

## 5. 想彻底不要电脑（P1）需要什么
