# 星尘 UI 体系改造记录

> 目标：不让每个页面自己发明样式。先把组件层做对，再让页面复用。
> 36 个页面共 6 个共享组件，改组件层 = 全 App 同时生效。

## 一、组件层（本轮核心）

### StradustButton（83 处调用）

| 问题 | 原状 | 现在 |
|---|---|---|
| 三档尺寸没有区分 | SMALL 与 MEDIUM **都是 40dp** | SMALL 36 / MEDIUM 44 / LARGE 52 |
| 触控热区不达标 | 36~40dp，低于 Material 48dp 建议值 | 视觉高度不变，`minimumInteractiveComponentSize()` 保证热区 ≥48dp |
| 长文案溢出 | 无 `maxLines`，长文字撑破按钮 | `maxLines=1` + 省略号 |
| 缺常用形态 | 只有文字 | 新增 `leadingIcon` / `loading`（转圈 + 自动禁用） |

### StradustCard（67 处调用）

| 问题 | 原状 | 现在 |
|---|---|---|
| 阴影画两遍 | `Modifier.shadow()` 与 `Surface(shadowElevation)` 同时生效，多一层图层且偏重 | 只保留 Surface 阴影 |
| 亮色下卡片与背景同色，边界消失 | 只有暗色模式加 0.5dp 边框 | 亮色也加 0.5dp 极细边框（亮色 45% / 暗色 30% 透明度）|
| 内边距写死 | 一律 16dp，列表型内容无法调密/调疏 | 新增 `contentPadding` |
| 只有一种形态 | — | 新增 `CardVariant`：AUTO（默认）/ OUTLINED（分组容器，透明底+边框）/ FILLED（嵌套小块，次级底色） |

> 为什么用"极细边框"而不是加阴影：阴影在长列表里滚动会掉帧，
> 边框是零成本，且能同时解决亮色下卡片与页面同色的问题。

### 新增 PageKit（页面级公共件）

| 组件 | 解决的问题 |
|---|---|
| `StradustSectionHeader` | 各页手写区块标题，字号 13~17sp、留白 4~20dp 全不统一 |
| `StradustEmptyState` | 原来 **60 处**各自手写"暂无 xx"，图标/字号/有无引导按钮全不一样；内容带半透明底色，压在壁纸上也读得清 |
| `StradustListRow` | 列表行高 44~72dp 混排、无分隔、无统一尾部区 |
| `StradustRowDivider` | 分隔线左缩进，不切断左侧图标 |
| `StradustPageContent` | 页面左右边距 16/18/20 混用 |

### StradustTopBar（几乎所有子页面）

非渐变顶栏与内容同色，滚动时标题与正文糊在一起。补一条 **0.75dp 分隔线**
（用 `drawWithContent` 画在底部），结构立刻清楚，且不改任何页面的配色。

### 真机发现并修掉的问题

日记页空状态原先直接压在壁纸上，浅色文字几乎不可读（截图实测）。已给空状态内容套
半透明底（`background.copy(alpha=0.68f)`，圆角 24dp，最大宽 320dp），
任何壁纸下都能读，纯色页也不突兀。

## 二、页面层

### 首页（原来"太空"）

原因：页面只有一张角色卡 + 侧边栏。一个人设时，卡片下面整片空白。

改法：在角色列表下方插入 **快捷入口 4×2 网格**（日记 / 相册 / 难忘时刻 / 成就 /
打卡 / 群聊 / 日程 / 时光胶囊），复用已有回调，不新增页面。
格子热区约 64dp，单手可点；侧边栏保留，两者不冲突。

### 设置页（原来"太挤"）

根因不是"信息太多"，而是两个行组件没有尺寸约束：

- `SettingSwitchRow`：**没有最小行高、没有上下内边距**，行高只由文字撑开（约 36dp）
- `SectionTitle`：上下各 8dp，二十几个分组连续滚动时组与组之间没有"断开感"

改法：

- 设置行 `heightIn(min = 56.dp)` + 上下 8dp；标题与副标题之间加 2dp、副标题行高 16sp
- 分组标题 `heightIn(min = 48.dp)`，上 16dp / 下 6dp（**上留白 > 下留白**，形成"分组断开、组内贴紧"的节奏）

覆盖 **22 个开关行、16 个分组标题**。

### 空状态统一（6 个页面）

日记 / 相册 / 收藏 / 时光胶囊 / 成就 / 角色世界书方向。统一形态：
柔和底色圆底 emoji + 一句主文案 + 一句"下一步该做什么"提示 + 可选操作按钮。

`compact = true` 用于非整屏场景（如列表内、分类筛选后）。

## 三、可读性

全 App `fontSize = 10.sp` → `11.sp`（15 个文件）。10sp 在 1080p / 450dpi 上约等于
8pt，中文笔画会糊；11sp 是这套 theme 下的可读下限。

## 四、未做（需要真机截图才能定）

- 聊天气泡内边距与最大宽度：改动影响所有会话观感，必须在真机上逐条看
- 各页左右边距从 20dp 统一到 16dp：需要每页确认固定宽度子元素不被挤坏
- 设置页"常用 / 权限 / 高级"三级折叠：属于信息架构调整，不只是样式

## 五、扩展方式

新增一个设置行：用 `StradustListRow`（有 Switch 就放进 `trailing`）。
新增一个区块：`StradustSectionHeader` + 内容 + `StradustRowDivider`。
新增一个空列表：`StradustEmptyState`，别自己画 Icon + Text。

> 铁律：**页面里不出现裸的 `fontSize=` + `padding=` 组合来定义"区块外观"**。
> 一旦这么写，下一轮改版就得再翻 36 个文件。

### 真机再修两处

| 问题 | 现象 | 修法 |
|---|---|---|
| 主题色块被裁切 | 一行横向滚动，第 5 个圆被卡片边缘切一半，看着像渲染错误、也看不出可滑 | 改 6 列 × 2 行网格（`chunked(6)` + `weight(1f)`），12 个主题一眼全在 |
| 空状态压在壁纸上不可读 | 日记页文字糊成一片 | 内容加半透明底（0.68 alpha、圆角 24dp、最大宽 320dp）；纯色页实测几乎无感 |
