# 微信界面结构全图（2026-11-01 逐板块实测）

微信是**原生控件**，四个 tab、列表、按钮全都在无障碍树里，**不需要截图识别**。
真正麻烦的不是"读不到"，而是下面四个结构性陷阱。

## 四个陷阱（先看这个，能省一半时间）

### 1. 四个 tab 是同时挂载的，非当前 tab 的坐标是**负数**

微信主界面一个 Activity（`LauncherUI`）装了四个 tab。dump 出来的树里，
**所有 tab 的内容都在**，不在屏幕上的那些 `bounds` 是负的，例如：

```
通讯录页 dump 里混着聊天列表：
  d17 LinearLayout「」(0,247,1080,466) #cj1      ← 这是聊天列表的行（但也可能是通讯录的）
  d23 View「公众号」(0,289,-263,359) #kbq        ← right < left，说明在屏幕外
```

**判断"这个元素在当前页面上吗"：`right > left` 且 `0 ≤ left` 且 `right ≤ 1080`。**
不满足就是在别的 tab 里，别点。

### 2. 点右上角「更多功能」出来的是 PopupWindow，不是新页面

`mCurrentFocus` 会变成 `Window{xxx u0 PopupWindow:1cd986c}`。
这时 dump 只能看到菜单本身（4 项），底下的页面内容全看不见——**这是正常的，不是读失败**。

通讯录右上角菜单（x 609~1065，每格 172px 高）：
`发起群聊 / 添加朋友 / 扫一扫 / 收付款`，都在 y=267 起、间隔 172。

### 3. 公众号用的是 Flutter，节点很少但文字都在

`plugin.brandservice.ui.flutter.BizFlutterTLFlutterViewActivity`，整页只有 **16 个节点**，
但标题、正文摘要、按钮全在 `text`/`desc` 里。**别被节点数少吓到**，照样能读能点。

同理 `搜一搜` 是 `WxaLiteAppLiteUI`（小程序容器），17 个节点，热榜文字都在。

### 4. 聊天记录**能读到**（之前说读不到是错的）

之前判断"微信聊天页消息文本不在树里、只能截图识别"——**这个结论是错的**。
错在采集深度：消息气泡在 **depth 19~21**，早期用的是 depth 8~20 的浅采集，正好切掉。

聊天页实际结构：

| 元素 | 资源 id | 说明 |
|---|---|---|
| 消息文本 | `#bkl` | 每条消息一个 TextView，文字完整 |
| 头像 | `#bk1` | 自己的叫「某某头像」 |
| 时间戳 | `#br1` | 「凌晨12:29」这种 |
| 系统提示 | `#bkl` | 「以上是打招呼的消息」也在这 |

读消息：全量采集后按 `#bkl` 取，按 y 坐标从上到下排序就是时间顺序。
判断"谁发的"看气泡左右：自己的气泡靠右（left > 400），对方靠左。

## 各板块结构

### 聊天列表（LauncherUI）

- 标题「微信(N)」`#text1`，右边两个图标：`#meb`（搜索）、`#plus_icon`（+ 菜单）
- 每条会话是一个 `#cj1` 行（高 219px），行内：
  - 未读数字 `#o_u`
  - 会话名 `#kbq`（**注意：VirtualView，text 有值但 desc 是 null**）
  - 时间 `#otg`
  - 消息摘要 `#ht5`
- **点会话要点行右侧空白**（x>850），点头像会弹资料卡，点名字没反应

### 通讯录（同 LauncherUI，切 tab）

顶部：标题「通讯录」`#text1`、搜索 `#jha`、更多功能 `#jga`

| 项 | 资源 id | 中心坐标 |

| 标签与权限 | `#t4m` | (347, 500) |
| 群聊 | `#n9` | (347, 670) |

下面按首字母分组（`#cfx` 是字母分组头），联系人是 `#kbq`。
底部「N个朋友」`#caj`。

- **新的朋友**：`FMessageConversationUI`，只有 9 个节点，有「已添加」状态

## 稳定操作路径（都在树里，不用记坐标也行）

```
发消息：  微信tab → 点会话行右侧空白 → 点输入框(#bkk) → 输入 → 点发送
读消息：  进聊天页 → 全量采集 → 取 #bkl 按 y 排序
搜索：    微信tab → 点搜索(#meb) → 输入 → 点结果行(#ltk) 或 联系人分组
找人：    搜索比翻通讯录快，通讯录只在"知道在哪个字母下"时更方便
```

## 判断"成功没有"的可靠依据

- **发送**：输入框 `#bkk` 变成空 + 列表末尾多一个自己发的 `#bkl`（右侧）
- **进对页面**：看 `mCurrentFocus` 的类名（见各板块标题上的类名）
- **弹窗挡住**：`mCurrentFocus` 变成 `PopupWindow:xxx` 时，先按坐标点菜单项，别去读页面

## 不建议自动做的

- 收付款、转账、红包：涉及钱，必须用户确认
- 删除聊天/清空聊天记录：不可逆
- 点击「更多功能」九宫格里的「拍摄」：会打开相机并申请权限
