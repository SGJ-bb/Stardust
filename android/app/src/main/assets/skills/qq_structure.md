# QQ 界面结构全图（2026-11-01 逐板块实测）

QQ 整体可读性**比微信好**：会话列表每行都带完整描述，群聊、搜索结果、群成员全是原生控件。
但有五个坑跟微信完全不同，不知道就会一直原地打转。

## 六个陷阱（先看这个）

### 0. 点会话行 / 发按钮：无障碍点击会「假成功」，要用坐标点

实测三次都踩到：对会话行（`#aua`）和发送按钮（`#send_btn`）调用无障碍 click，
接口返回成功，但 QQ 什么都没干——页面没跳、消息没发。
只有**真实触摸**（坐标 tap）才生效。

所以：
- 点会话行 → 优先 `{"action":"tap","x":600,"y":行中心}`
- 点发送 → 同样用 tap 点 (921, 2030)
- 一次点击后 `read` 一看还是原页面，**立刻换坐标点**，别用同样的方式再点一遍
  （实测这一点浪费了 4 轮、占掉整次任务一半时间）

### 1. QQ 是**单 Activity**：页面变了，类名不变

整个 App 几乎都在 `com.tencent.mobileqq.activity.SplashActivity` 里跑。
进聊天、回列表、切 tab，`mCurrentFocus` 一直是 `SplashActivity`。

**所以绝对不能用"包名/类名变了吗"判断有没有跳转。**
判断当前位置只能看**内容**：标题文字（`#ivTitleName` 或 `#5md`）、
有没有 `#input` 输入框、有没有 `#elv_buddies` 好友列表。

实测教训：AI 因为类名一直是 SplashActivity，连做了三次 `read` 才敢动手，
白白多花十几秒。

### 2. 会话列表每行有**完整描述**，直接用，不要自己拼

每个会话行是 `#aua`（RelativeLayout），`contentDescription` 形如：

```
喵喵, ,伊蕾娜: [图片] @孤独剑客· 欢迎新人~!! ,昨天 晚上11:00
↑会话名  ↑未读数        ↑发送者: 摘要                        ↑时间
```

「有N条未读」这五个字也是描述的一部分。**判断"有没有新消息"直接读这个字符串就行。**

### 3. 联系人「好友」列表**读不到名字**（App 侧缺失，不是我们读法的问题）

「好友」子 tab 下，每一行只有 `#group_item_layout` / LinearLayout 容器，
**子节点一个文字都没有**。

已经用**系统自带的 uiautomator 独立验证过**（它和 TalkBack 读的是同一棵无障碍树）：
dump 出来的 XML 里，好友行的 `text=""`、`content-desc=""`，一个字都没有。
说明这是 QQ 自己没把名字上报给无障碍，**换任何读屏软件都读不到**——
不是服务身份没伪装好，也不是采集深度不够。

**能用 OCR 补**：调 `device {"action":"ocr"}`，会把"树里没有、但屏幕上看得见"的文字
识别出来并合并进快照（每条都带坐标，可以直接点）。

⚠ 第一次用会弹系统授权窗「是否允许录制/投射您的屏幕」，**必须点一次「允许」**——
这是 Android 的规定，任何不 root 的 App 想拿屏幕像素都要过这一步。点过之后就一直有效
（重启设备或重装 App 需要重新点）。

实测效果：好友列表 OCR 后补进 16 条，AI 能直接说出「『时光机』、lazy boy、看见不评论的没有吉吉」。
注意 OCR 会把在线状态和昵称连在一起（`[4G在线]看见不评论的没有吉吉`），按 `[xG在线]` 前缀切开即可。

⚠ QQ 打开时可能先弹**应用锁**（`AuthLaunchLockedAppActivity`，标题「输入锁屏密码访问"QQ"」）。
那是华为系统级的应用锁，密码不一定等于锁屏密码。输错有次数限制（会提示「还有 N 次机会」），
**不要乱试**，直接告诉用户需要他解锁。

| 联系人页的子 tab | 名字能不能读到 |
|---|---|
| 好友 | ✗ 自绘 + 未上报，需 `ocr` 兜底 |
| 分组 | ✗ 同好友 |
| 群聊 | ✓ `#text1` |
| 频道 / 机器人 / 设备 | ✓ |

**要在好友里找人，不要翻列表——走搜索**（见下面「搜索」一节），
搜索结果是原生控件，名字、QQ号、分组全在。

### 4. 侧边抽屉（头像 → 相册/收藏/钱包/设置）**不在无障碍树里**

点左上角头像 `#ba1`（desc「账户及设置」）会滑出抽屉，
但 dump 出来的还是被缩进 54px 的**原页面**，抽屉内容一个字都读不到。
里面能看到的是：头像、昵称、切换账号、相册、收藏、文件、钱包、会员中心、
个性装扮、免流量、设置、日间、天气。

**结论**：抽屉里的东西只能按坐标点，或者从别处绕：
- 收藏 → 聊天页「更多功能」里的「收藏」也能进
- 群相关设置 → 群聊页右上角 `#3vz`（这个在树里）
- 全局设置 → 只能点头像 → 点抽屉左下角「设置」（坐标 95, 2129 附近）

### 5. 「返回」按钮的描述里带着未读数

聊天页左上角 `#ivTitleBtnLeft` 的 desc 是 **「返回消息未读54」**，
不是干净的「返回」。用文字精确匹配「返回」会失败，要用包含匹配，或者点坐标 (66, 176)。

|---|---|---|
| 消息 | (135, 2200) | 会话列表，未读角标 `#khc`（文字是数字，如「54」） |
| 频道 | (405, 2200) | 频道内容流 |

## 各板块结构

### 消息（会话列表）

- 搜索框 `#3b7` + EditText `#3_g`「搜索」，点击进入独立搜索页
- 会话行：`#tu6` 容器 > `#aua`（**desc 是完整摘要**）> `#a2o` 头像 + 若干 TextView
- 行高 218px，第一行从 y=435 开始
- **点行中间就行**（不像微信必须点右侧空白），整行 `#aua` 可点

### 聊天页

| 元素 | 资源 id | 坐标/说明 |
|---|---|---|
| 返回 | `#ivTitleBtnLeft` | desc「返回消息未读N」 |
| 会话名 | `#5md`（群）/ 标题区 | 群名 |
| 群人数 | `#5mb` | 「(154)」 |
| 听筒模式 | `#up5` | |
| 聊天设置 | `#3vz` | 群聊页右上角，进群设置 |
| **输入框** | `#input` | (49,1966,776,2093)，中心约 (412, 2030) |
| **发送按钮** | `#send_btn` | (812,1966,1031,2093)，中心约 (921, 2030) |
| 消息文本 | `#sit` | TextView，正文在这 |
| 发送者昵称 | `#siw` | 群聊里每条消息上方 |
| 消息头像 | `#sgy` | |
| 等级标签 | 无 id | 「LV2 壹元」这种 |

底部工具条（无 id，靠 desc）：`语音 / 相册 / 拍照 / 红包 / 表情 / 更多功能`
中心 y ≈ 2165，x 依次 90 / 270 / 450 / 630 / 810 / 990。

**发送按钮是常驻的**（不像微信要等输入框有字才出现），所以「点发送」永远点得到。
判断发出去没有，同样用 `"expect":"输入框为空"`。

```
第一行 y≈1606：语音通话   视频通话   位置     文件
第二行 y≈1930：收藏       打卡       群收款   直播间
```

### 搜索（独立 Activity：`UniteSearchActivity`）

| 元素 | 资源 id |
|---|---|
| 搜索框容器 | `#search_box` |
| 输入框 | `#3_g`（**中文无障碍写入可用**） |
| 清空 | `#3_a` |
| 取消 | `#39x` |

未输入时：「搜索指定内容」+ 找人/群 `#bl9`、表情 `#blc`、小程序 `#bld`。

输入后结果按 `#title` 分组（联系人 / 群聊 / …），每条行是 LinearLayout：
- 名字 `#title`
- QQ号/群号 `#j64`，形如「(3161137459)」
- 补充说明 `#bgt`，形如「来自分组:我的好友」/「包含：关键词」
- 最上面是分组标题 `#title`「联系人」「群聊」

**找人一律走这里**，比翻好友列表快且准。

### 群聊设置（`QPublicFragmentActivity`）

标题「群聊设置」，返回左上，右上「分享群聊」。往下：

- 群头像 `#head`、群名 `#k0i`、群简介 `#j5r`
- 群聊成员 `#3a0` / 「查看154名群成员」`#3a9`
- 成员网格：每格 RelativeLayout + 昵称 `#f5e`，最后一格是「邀请」
- 群聊信息分组：群聊名称等，行是 `QUISingleLineListItem`

### 频道

- 顶部昵称 `#2g`，右边两个入口 `#aju` / `#tfy`
- 「频道问问」`#65o` + 说明 `#659`
- 分类 tab「推荐」等（无 id，靠文字）
- 「精选频道」`#w7q` + 格子 `#wrw`（QQ水浒 / QQ反诈卫士 / 天闻角川官方频道 / 更多）

### 动态

顶部标题 `#ivTitleName`、更多 `#ivTitleBtnRightImage`、样式选择 `#xzc`、
搜索框 `#3b7`。下面整列都是 FrameLayout + `#letsTextView`：

```
好友动态（右侧「新发表」） / 游戏中心 / 小游戏 / 小说与动漫 / 农场 / 购物
```

## 稳定操作路径

```
发消息：  消息tab → 点会话行(#aua，整行可点) → 点输入框(#input)
        → 输入 → 点发送(#send_btn, expect:"输入框为空")
找人：    消息tab → 点搜索框(#3b7) → 输入名字 → 点结果里「联系人」分组下的行
群设置：  进群 → 点右上 #3vz
读群成员： 进群 → 群设置 → 成员网格 #f5e
```

## 判断"到底在哪一页"（因为没有类名可看）

| 看到这些 | 就是这一页 |
|---|---|
| `#aua` 一堆、`#khc` 未读角标 | 消息列表 |
| `#elv_buddies` 或 `#02u` 子 tab 栏 | 联系人 |
| `#input` + `#send_btn` | 聊天页 |
| `#search_box` + 「搜索指定内容」 | 搜索页 |
| `#k0i` + `#3a0`「群聊成员」 | 群聊设置 |

## 不建议自动做的

- 钱包、红包、群收款：涉及钱，必须用户确认
- 抽屉里的「切换账号」：会把当前登录态换掉
- 删除好友/退群：不可逆
