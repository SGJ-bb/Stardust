# 微信发消息

## 完整路径

```
打开微信 → 点右上角搜索图标 → 输入对方名字 → 点搜索结果里的联系人
        → 点聊天窗口底部输入框 → 输入内容 → 点「发送」
```

**优先用搜索找人。** 聊天列表虽然也能读到（会话名、消息摘要都在），但层级深、位置会随滚动变，
搜索一步到位更稳。不管对方在不在常驻列表，搜索都比翻列表快。

## 三个微信特有的坑

### 1. 界面结构默认读不到

微信不上报界面元素：能拿到的只有一个空壳（包名对、但没有任何内容）。
所以**不要**一上来就找按钮，先判断：

- 如果连「微信」两个字都读不到 → 直接按截图识别走
- 如果读得到（说明当前用的是系统级无障碍身份）→ 正常用结构定位

读不到时不要去改系统设置，直接降级到截图识别即可。

**注意各页面的差别很大：**

| 页面 | 能读到什么 |
| --- | --- |
| 聊天列表 | 会话名、消息摘要、未读角标都有（但层级很深，翻页后位置会变） |
| 搜索结果 | 有，联系人名、群名都在 |
| 聊天窗口 | 有输入框和「发送」按钮，但**聊天记录内容要另外确认** |

所以想读聊天记录、要判断"上次说到哪了"，必要时用截图识别文字补一下。

### 2. 点名字文字没反应

搜索结果里，**名字那一行文字是「可选择文本」，点它没有反应**。
真正能进入会话的位置是：

| 点哪里 | 结果 |
| --- | --- |
| 名字文字 | 没反应 |
| 头像 | 弹出资料卡（不是聊天窗口） |
| **名字右侧的空白** | 进入聊天 ✓ |

所以找「联系人」时，定位到名字之后，**往右偏移点空白**，别直接点文字。

### 3. 搜索结果里同一个名字会出现好几次

典型分布：

- 顶部「最常使用」的会话（下面带一行摘要，含这个名字）
- 「联系人」分组里的真人
- 「群聊」分组里的群（摘要含这个名字，形如「包含：某某」）
- 最下面是「聊天记录」里的历史消息

**优先点「联系人」分组里的那个**（一般在屏幕上方三分之一）。
如果只有摘要行匹配上，说明那是群聊或历史记录，不要点——会进错地方。

## 输入与发送

1. 点聊天窗口底部的输入框（**点偏上一点容易落到消息列表上**，宁可点低一点）
2. 输入中文用「写剪贴板 + 粘贴」，不要用命令行注入
3. 输入框里出现文字后，右下角会出现「发送」按钮，点它
4. **发送后页面不会跳转**，别用「页面变了」判断成功；
   应该看聊天记录里有没有出现刚发的这条消息（或输入框是否被清空）

## 自检

发完回读一次：

- 输入框清空了 → 大概率已发出
- 聊天列表里出现了新消息 → 确认成功
- 输入框还有字、按钮还在 → 没发出去，重点一次「发送」

如果对方名字搜不到，先确认是备注名还是昵称、有没有同名联系人，再问用户。
