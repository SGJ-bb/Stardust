# 内置技能（随 APK 打包）

这个目录放的是**和用户无关的通用操作知识**：怎么在第三方 App 上把界面自动化做对。
应用启动时会调用 `SkillStore.importBundled()` 把它们导入到技能库（`files/skills.json`），
之后 AI 就能在系统提示词的「技能清单」里看到，需要时用 `skill` 工具 `action=get` 读正文。

## 规则

1. **只写方法论，不写个人信息**。不要出现：具体联系人名、聊天内容、设备型号、
   本机路径、坐标常量、用户的应用包名。
2. **一个文件一个技能**，文件名即兜底 id。frontmatter 字段：
   ```yaml
   ---
   id: sk_xxx                    # 稳定 id，改正文不要改它
   name: 技能名
   description: 一句话，给 AI 判断要不要读
   scope: global | app           # app 时要给 appName / appPackage
   appName: 微信
   appPackage: com.tencent.mm    # 只写公开的 App 包名
   triggers: 触发词, 用逗号分开
   source: bundled
   rev: 1                        # 改内容必须 +1，否则老用户升级拿不到
   ---
   ```
3. **正文用「症状 → 怎么做」写**，不要写实现细节（那些属于代码注释）。
   目标是让 AI 读完就知道下一步做什么，不需要再猜。

## 升级已有技能

改内容 → `rev` 加一 → 发版。老用户升级后，`rev` 比记录值大就会覆盖正文，
但会保留使用次数/成功率统计；用户或 AI 手动改过的内容同样会被覆盖（这是刻意的：
内置技能以发版内容为准）。

## 新增技能

直接加 `.md` 文件即可，首次启动会自动补进库，不需要迁移脚本。

## 删除技能

删文件不会删掉用户机器上已经导入的那条。要下线，请在 `SkillStore.importBundled()`
里加一条禁用名单，或者让设置页支持隐藏。
