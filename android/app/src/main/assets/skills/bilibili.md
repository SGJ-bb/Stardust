# B站（哔哩哔哩）

**好消息：B站是原生控件，界面结构能完整读到**（有资源 id、有内容描述），
不需要截图识别。这是它跟微信最大的区别，微信的列表要深到用深度 23 才看得见。

## 完整路径

```
启动B站 → 点顶部搜索栏(#expand_search) → 输入关键词 → 点"搜索"(#action_search)
        → 点结果里任意视频卡片 → 等播放器加载
```

## 第 0 步：怎么启动（别绕路）

**直接调 `device` 工具**：

```json
{"action":"app_start","pkg":"tv.danmaku.bili"}
```

不要下拉通知栏搜应用名，也不要在桌面上翻图标找——那要多走三四步，还容易点错。
包名就是 `tv.danmaku.bili`，记牢。

## 关键元素

### 首页
| 元素 | 资源 id | 位置（1080宽） | 说明 |
|---|---|---|---|
| 搜索栏 | `#expand_search` | (240,138)-(727,252) | 点它进搜索页，**这是唯一入口** |
| 头像/登录 | `#avatar_layout` | (34,128)-(193,263) | 没登录会显示"登录" |
| 顶部频道 | 无 id，`desc` 形如「推荐,6之2,标签」 | y≈290-412 | 直播/推荐/热门/动画/影视 |

### 搜索页
| 元素 | 资源 id | 说明 |
|---|---|---|
| 已输入的文字 | `#search_fake_text` | 输入框本体（原生 EditText，**无障碍写入可用**） |

| 搜索按钮 | `#action_search` | 在右边 (864,128)-(1080,243) |

### 搜索结果（综合 tab）
```
用户卡片 #user_info      ← 上面是UP主信息，别点错
视频卡片 ViewGroup[可点] ← 下面才是视频，每个卡片里有：
   #play_num  播放量（如"10.9万"）
   #title     视频标题
   #post_time 发布时间
```
**点视频卡片本身**（整块 ViewGroup 可点），不要点里面的文字。

## 三个坑

### 1. 启动就弹登录窗
类名 `SmsLoginDialogActivityV2`，只有 12 个节点，标题是「登录注册解锁更多精彩内容」。

**先关掉**：点 `#close`（右上角，约 (958,666)），否则后面什么都点不到。
不登录也能搜、能看，只是推荐内容不一样。

### 2. 搜索结果里混着 UP 主卡片
搜「薛之谦」，第一个结果块是 UP 主主页（带"关注"按钮），不是视频。
要找视频往下看，卡片里带 `#play_num`（播放量）的才是。

### 3. 播放成功的判断
进视频页后类名变成 `com.bilibili.ship.theseus.detail.*`（这些是 B 站内部的详情页）。
别看类名就以为在播——**要看播放器上的进度数字**，格式 `00:13 / 05:57` 这种，
时间在走就是真的在放。

## 最后一步：让它真的响

进到视频详情页之后，**很可能还是没在播**（播放器一片黑、没有声音）。
补这几下：

1. 点屏幕中央（约 `540,600`）—— 拉起控制栏
2. 点控制栏中间的播放键（通常也在屏幕中央，`540,600` 附近）
3. 等 2 秒，再 `read` 一次，看进度数字有没有在走

**判断标准只有一个**：进度时间在变化（比如从 `00:03` 变成 `00:06`）。
看不出来就再点一次；连续两次都没变化，才认为这个视频放不了，返回列表换一个。

⚠ 注意：B 站的播放器是硬件渲染的，**截图里经常是纯黑**，这不代表没播。
不要用"截图有没有画面"判断，用进度数字判断。

## 已经验证过的流程（2026-10-31 实测）

搜「薛之谦」→ 点第一个视频 → 播放器显示 `00:13 / 05:57`，弹幕正常滚动。
全程只用界面结构定位，没有一次截图识别。

## 视频页的互动按钮（资源 id 全在，按 id 点最稳）

视频详情页底部那一排按钮，坐标是 (41,1455)-(1080,1651) 这一条，从左到右：

| 按钮 | 资源 id | 内容描述会变成 |
|---|---|---|
| 点赞 | `#frame_like` | 「已点赞，10871个点赞」 |
| 投币 | `#frame_coin` | 「投币，5301个投币」 |
| 收藏 | `#frame_fav` | 「已收藏，19216个收藏」 |
| 分享 | `#frame_share` | 「分享，1.1万」 |

**判断一个按钮点没点上，看它的描述里有没有「已」字**，不要看颜色、也不要看坐标变化。
这条比什么都可靠：`已点赞` / `已收藏` / `投币`（没投过就是「投币」，没有「已」）。

⚠ 这几个按钮的 `bounds` 偶尔会报成负数（如 `(0,1455,-840,1651)`），那是横向滚动容器里的
相对坐标，**不代表元素在屏幕外**。遇到负数别放弃，改用 id 或按上面那条 y 区间直接 `tap`。

### 关注的按钮

UP 主主页、视频页上的「+ 关注」都在结构里，点完描述会变成「已关注」。
按描述判断，别按位置判断。

## 四个功能，实测能不能做（2026-10-31，同一台机）

| 功能 | 结果 | 说明 |
|---|---|---|
| 读评论 | ✅ 可以 | 点底部「评论」tab → 评论区展开，楼层文本都在树里 |
| 点赞 | ✅ 可以 | 点 `#frame_like` |
| 收藏 | ✅ 可以 | 点 `#frame_fav` |
| 关注 | ✅ 可以 | 搜 UP 主名 → 主页 → 点关注 |
| 投币 | ✗ 受账号限制 | 点开弹窗提示「硬币余额不足（0.0）」。这是账号问题，不是操作问题 |
| 发评论 | ✗ 受账号限制 | 能输入、能点发布，但 B 站弹「需要升级成为LV2后才可以评论，先去答题吧」 |

**遇到上面两个限制，不要反复重试**，直接把原话告诉用户：
`投币失败，账号硬币余额为 0` / `评论失败，B站要求账号等级升到 LV2`。
重试只会白烧十几次动作。

## 发评论的完整路径（等级够时照这个走）

```
点底部「评论」tab → 点评论输入框（提示文字是"评论千万条，等你发一条"）
→ input 输入内容 → 点「发布」
```

输入框是原生 EditText，**无障碍写入可用**，不需要走剪贴板。
发布后如果弹出「请转正答题」的对话框，就是等级不够，不是输入没成功。

## 又一个坑：点「搜索」按钮后别急着判失败

点 `#action_search` 之后，B 站要 **1~2 秒**才把结果列表刷出来。
这段时间里屏幕内容可能一点都不变，如果给这一步加了 `expect:"变化"`，会被判成失败，
然后就会重复点、或者以为没搜到。

**做法**：搜索按钮这一步**不要加 expect**，点完直接 `wait 2000` 再 `read`。
判断搜到没有，看结果页有没有 `#play_num`（播放量）这种节点。
