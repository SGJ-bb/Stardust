### 开发目的（≤50字）
开发一款以 Live2D 虚拟形象呈现的 AI 桌宠伴侣，提供智能对话、情感记忆与语音陪伴，满足用户的个性化情感陪伴与娱乐社交需求。

### 面向领域 / 行业（≤50字）
面向人工智能与娱乐社交领域：智能对话机器人、虚拟形象陪伴、语音交互、情感计算等应用方向。

### 软件的主要功能（500~1300字）

**1. 智能对话引擎**
实现对用户自然语言的实时理解与拟人化回复。系统内置"星尘"AI角色人格设定，支持多轮上下文对话、实时情感识别（输出6种情感标签）与角色动作映射，可切换多个可导入的虚拟角色形象。对话引擎接入主流大模型API，具备流式/分段输出能力，并内置文本安全与会话管理机制。

**2. Live2D 拟真渲染**
基于 Live2D Cubism SDK 与 OpenGL ES 2.0，在手机全局悬浮窗中实时渲染 2D 动画角色。支持不同情绪标签驱动面部表情、尾巴摆动、耳朵抖动、脸红、伸懒腰等多种动画动作，实现"AI 情感-角色表现"实时同步。支持导入并切换用户自定义的 Live2D 模型。

**3. 长期记忆与记忆池管理**
实现三层记忆体系：会话内短期记忆、跨场景共享记忆池、以及按角色隔离的记忆池。系统定期将重要对话内容抽取为长期记忆，支持记忆检索与回溯；提供记忆管理界面，可查看、按角色筛选、删除指定记忆，并支持记忆池的合并整理与日记式归档。

**4. 语音交互**
集成语音识别（ASR）与语音合成（TTS）。支持中文语音输入对话、语音播报 AI 回复，并根据情感标签对语音音高、语速进行情感化变调；提供本地离线 TTS 降级方案，断网时也能输出语音。

**5. 主动互动引擎**
内置基于规则的主动互动引擎，根据时间、电量、(可选的)当前屏幕应用类别等触发条件，主动向用户发起问候与闲聊；具备频率控制与智能退避策略（电量低/过热时自动降频），避免打扰。

**6. 屏幕感知与隐私保护**
在用户授权无障碍服务后，仅识别当前前台应用的应用包名并将其分类为社交/视频/办公等抽象类别标签，用于个性化互动语境；屏幕内文字内容不离开本机，隐私数据可一键清除，且提供功能总开关。

**7. 情感与好感度系统**
维护角色对用户的好感度数值，随长期互动动态增减；配合维度化情感状态（愉悦/激活/支配及疲劳、好奇、亲和等），使角色互动更具成长性与个性化。

**8. 虚拟世界与世界观拓展**
提供可扩展的"虚拟世界"设定，角色的记忆与互动可跨场景持续累积，构建连贯的角色世界观。

**9. 设置与个性化**
提供完善的设置面板：接口与服务配置、AI 功能开关、语音/情感参数、Live2D 模型管理与切换、记忆管理、关于信息、数据备份与清理等。

### 软件的技术特点（≤100字）
采用"云端大模型 + 本地轻表现"混合架构；Live2D 情感实时驱动；基于角色隔离的三层记忆机制；自定义人物设定注入与模型可分换；屏幕感知本地脱敏处理，兼顾隐私与个性化；支持离线降级，成本与性能平衡。
