## 一、成果简介

Stradust 是一套跨 Android／PC／iOS 三端的 AI 伴侣开源框架，代码总量约 15 万行（Android 端 Kotlin 9.4 万行，PC 端 Tauri/Rust + React 约 4.3 万行），采用 Kotlin + Tauri/Rust + React 混合技术栈。项目以"框架先行、内容用户填"为设计哲学，把角色人格、外观、语音、模型与世界设定全部开放自定义，核心能力包括：Tavern 角色卡导入导出（兼容 SillyTavern 生态）、12 套主题与气泡皮肤、Live2D 模型驱动、三层记忆与本地 RAG 检索、4 种 TTS 引擎、10 余个内置插件与技能库、无障碍屏幕感知。架构上以"云端重智能 + 本地轻表现"平衡成本与体验。

成果已进入用户验证阶段：项目以 MIT 协议开源，自 2026 年 5 月起完成 16 个版本迭代（v11 至 v26），积累真实用户社群 138 人，用户反馈直接驱动版本演进，已形成稳定的迭代闭环。

## 二、转化需求

成果处于"技术成熟、市场待验证"阶段，转化需求集中于四个方面：

1. 算力与模型资源：大模型 API 额度及本地推理算力支持，用于降低使用门槛与测试成本；
2. 资金支持：用于服务器运维、内容安全合规及全职开发投入；
3. 渠道与推广：应用商店上架、平台分发资源及垂直社区推广；
4. 团队补充：像素美术与运营人才，支撑在研的"像素虚拟世界"新方向。

期望通过资源对接，完成从种子用户到规模化用户的跨越。
