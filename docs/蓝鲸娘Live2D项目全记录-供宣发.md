## 2. 做了什么（按时间线，可用于"制作过程"类内容）

1. **AI 立绘 → 语义分层**：see-through 输出 28 个部件
2. **人工补件**：头套 10.5 万像素、尾鳍、帽兜绒球共 3 件是"恒定缺失"（AI 分层通病），用「原图 alpha ∧ 全层并集取反」精确算出缺哪些像素，只补缺失部分、不重画
3. **层序纠错**：发现"大衣挡住大腿导致露肉色"、"眉毛被画到头发上"（原画里眉毛本在刘海后）两处结构性错误，重排深度后修掉
4. **嘴部重建**：原图闭嘴 → 生成张嘴变体 → 拆成 `mouthbody`（唇点）+ `mo_open`（张口腔），实现 6 档自然开合，全程无"双线"残影
5. **绑定**：眼（左右独立眨眼/视线/眼神果冻）、眉、嘴、头发 HI 物理、尾鳍/绒球/双手摆动
6. **3 套表情**：爱心瞳、泪眼、怒眉，用"变体直取"——同一张立绘生成表情变体，按几何掩码直取贴片，**不重画**
7. **6 个新动作**：程序化生成 motion3 曲线，**不打开 Cubism Editor**（Q弹/惊讶/打瞌睡/害羞/生气/左右看）
8. **双端运行时**：Electron 桌宠 + Web 端（stradust-pc）跑同一个模型
9. **上架 + 自动发货**：闲鱼两条链接，拍下自动发网盘，关键词精准匹配防串货

## 4. 竞争口径（避免夸大，也要说清位置）

- 同价位（¥9.9–19.9）：市场多是 **3–5 表情 + 单段口型 + 无手臂** 的 AI 皮套，我们属于**同价位上游**（10 动作、独立眨眼、11 组物理）
- 中价位（¥50–300）：对手通常 8–12 表情、5 段口型（A/I/U/E/O）、头发 3–5 段物理、手臂参数
- 高价位（¥300+）：手工分层 150–400 层，有画师 + 绑师双人力
- **我们的差**：口型单段、无手臂参数（手与大衣连体，不能真挥手）、图层数受 AI 分层上限
- 诚实表述建议：**"AI 辅助生成 + 人工分层绑定调参"**，不要写"纯手工绘制"
